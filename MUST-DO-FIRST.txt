   ANF3 Air System > 1) Check schema / configuration

   ต้องขึ้น OK ทุกบรรทัด

   > กดดินสอ (Edit) ข้าง Active deployment
   > Version: New version
   > Deploy

   ⚠️  ถ้าไม่ทำขั้นนี้ จะยังเจอ error เดิม!
