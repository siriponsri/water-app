==========================================
ANF3 Laboratory Records - Quick Start
==========================================

อัปเดตโค้ดเสร็จแล้ว! ทำตามนี้:

1. AIR (air-test):
   - Extensions > Apps Script
   - ลบโค้ดเดิม → วางจาก apps-script-deploy/01-air-user/Code.gs
   - Save → รีเฟรชชีต
   - เมนู "1) Check readiness" → ต้อง OK

2. WATER (water-r):
   - Extensions > Apps Script
   - ลบโค้ดเดิม → วางจาก apps-script-deploy/03-water-user/Code.gs
   - Save → รีเฟรชชีต
   - เมนู "1) Check readiness" → ต้อง OK

3. CV (Testing):
   - Extensions > Apps Script
   - ลบโค้ดเดิม → วางจาก apps-script-deploy/05-cv-user/Code.gs
   - Save → รีเฟรชชีต
   - เมนู "1) Check readiness" → ต้อง OK

4. แก้ Building 11/19 (สำคัญ!):
   ใน RPP2-air-record:
   - Extensions > Apps Script
   - เมนู "ANF3 Air System" > "2) Setup approved active tabs"
   - เมนู "1) Check schema / configuration" → ต้อง OK
   - Deploy > Manage deployments > Edit > New version > Deploy

   ทำซ้ำกับ RPP2-water-record และ RPP2-cv-record

5. ลองซิงค์:
   - air-test > เมนู "ซิงค์ทั้งหมด (Air)"
   - ควรผ่านโดยไม่มี error แล้ว!
