Document Code Guide

แนวทางการกำหนดรหัสเอกสารและใบงานทดสอบ

1

รหัสเอกสารมาตรฐาน (Master Document)

aa-bb-ccnn
Document Format
aa ประเภทเอกสาร
bb รหัสแผนก
cc รหัสหมวดหมู่
nn ลำดับเอกสาร
2

ประเภทเอกสาร

Code ประเภท ตัวอย่าง
QP Quality Procedure QP-ANF3-WT01
WI Work Instruction WI-ANF3-AT02
FM Form FM-ANF3-CV01
LG Log LG-ANF3-GN01
3

รหัสหมวดหมู่งาน

AT
Air Testing
Settle Plate, Active Air, Compressed Air
WT
Water Testing
PW, PRW, WFI, PUS
CV
Cleaning Validation
Swab Test, Rinse Test
GN
General
Growth Promotion, Identification
4

รหัสใบงานทดสอบ (Worksheet)

งาน Format ตัวอย่าง
PW/PRW Routine WS-yy-nnnn WS-25-0001
PW/PRW PQ PQ-PW-yy-nnnn PQ-PW-25-0001
WFI/PUS Routine WP-yy-nnnn WP-25-0001
WFI/PUS PQ PQ-WFI/PUS-nnnn PQ-WFI/PUS-0001
Air Settle Plate SP-yy-nnnn SP-25-0001
Air Active AA-yy-nnnn AA-25-0001
Compressed Air CA-yy-nnnn CA-25-0001
Cleaning Validation CV-yy-nnnn CV-25-0001
Growth Promotion GP-[media]-yy-nnnn GP-TSA-25-0001
