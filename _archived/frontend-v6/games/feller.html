สูตรที่ใช้

เมื่อ N คือจำนวนรูทั้งหมด และ r คือจำนวน positive holes:

Pr = Σ(i=0 ถึง r−1) N ÷ (N−i)

ปัด Pr เป็นจำนวนเต็มใกล้ที่สุดตาม fixtures ของเกม

CFU/m³ = Pr × 1000 ÷ sample volume (L)

ข้อควรจำ

  • r ต้องอยู่ระหว่าง 0 ถึง N
  • เมื่อ r เข้าใกล้ N ค่า correction จะเพิ่มเร็ว
  • ใช้จำนวนรูและตาราง/วิธีของรุ่นเครื่องตาม SOP จริงเสมอ
