# พรอมป์สำหรับส่งงานออกแบบ

เลือกอันเดียวให้ตรงกับสิ่งที่ต้องการ อย่าใช้พร้อมกัน

---

## แบบ A — อยากได้ "ภาพ" ไว้ดูก่อนตัดสินใจ (Claude Design / artifact)

ใช้เมื่อยังไม่แน่ใจว่าจะเอาแนวไหน อยากเห็นหลายทางเลือกวางเทียบกัน
**ได้ออกมาเป็นภาพ ไม่ใช่โค้ดที่รันได้** เอามาใช้จริงต้องให้อีกเซสชันแปลงเป็นโค้ด

แนบ: `BRIEF.md` + โฟลเดอร์ `screens/` + `css/tokens.css`

> ช่วยออกแบบหน้าตาใหม่ให้ ANF3 Laboratory Records — เว็บอ่านบันทึกผลตรวจ
> จุลชีววิทยาในโรงงานยา ใช้บนเครื่อง Windows ในห้องแล็บ GMP ผู้ใช้เป็นเภสัชกร
> ที่ทำงานยืน บางครั้งใส่ถุงมือ อ่านง่ายสำคัญกว่าสวย
>
> อ่าน BRIEF.md ก่อน ในนั้นมีกฎที่ห้ามละเมิด โดยเฉพาะ 3 ข้อนี้:
> — ทุกสีต้องมาจาก tokens.css เท่านั้น
> — สีแฟ้มแทน "อาคาร" ไม่ใช่ของตกแต่ง ห้ามสลับ ห้ามไล่เฉด
> — สีกลางทุกตัว chroma ต่ำกว่า 0.02 ให้สีแฟ้มเป็นตัวเด่นที่สุดบนจอ
>
> ใน screens/ คือหน้าตาปัจจุบันทั้ง light และ dark
>
> อยากได้ 3 ทางเลือกสำหรับ**หน้า record workspace** (ดู `*-records.png`)
> ซึ่งเป็นหน้าที่ผู้ใช้อยู่นานที่สุด แต่ละทางบอกด้วยว่าแก้ปัญหาอะไร
> ทำทั้ง light และ dark ตัวเลขทุกตัวในภาพให้เขียนกำกับว่าเป็นตัวอย่าง

## แบบ B — อยากแก้ของจริงให้ใช้งานได้เลย (เซสชันเขียนโค้ด) ← แนะนำ

ใช้เมื่อรู้แล้วว่าจะเอาแนวไหน **ต้องส่งทั้งโปรเจกต์ ไม่ใช่แค่ design-handoff**
เพราะต้องแก้ไฟล์จริงและรัน gate

ในโปรเจกต์มี skill ออกแบบติดตั้งไว้แล้ว 4 ตัวที่ `.claude/skills/`
(hallmark, repaint, no-slop-ui, design-taste) — บอกให้มันใช้

> อ่าน `CLAUDE.md` แล้วต่อด้วย `HANDOFF.md` ก่อนแตะอะไร
>
> ใช้ skill `repaint` กับ `design-taste` ที่อยู่ใน `.claude/skills/`
>
> งานที่ต้องการ: [เขียนสิ่งที่อยากได้ตรงนี้ เช่น "ปรับหน้า record workspace
> ให้เห็นชัดขึ้นว่ากำลังจะพิมพ์ใบไหนบ้าง"]
>
> ข้อบังคับ:
> — ห้ามใส่ค่าสีนอก `apps/web/src/tokens.css` ถ้าต้องใช้สีใหม่ ให้เพิ่ม token
> — motion ใช้ได้แค่ transform กับ opacity บน easing/duration ที่มีชื่อใน
>   tokens.css และต้องมี prefers-reduced-motion เสมอ ห้าม transition outline
> — สีแฟ้มแทนอาคาร ห้ามใช้เป็นของตกแต่ง
>
> เสร็จแล้วต้องผ่านทุกตัวนี้ ถ้าไม่ผ่านให้แก้จนผ่าน ห้ามแก้ตัว gate เอง:
> ```
> pnpm check && pnpm test && pnpm build
> node validation/contrast.mjs
> node validation/validate_styles.mjs
> node validation/validate_non_game_contract.mjs
> node validation/validate_release.py
> ```
>
> แล้วเปิดดูในเบราว์เซอร์จริงด้วย screenshot ทั้ง light และ dark
> อย่าเชื่อว่าโค้ดถูกเพราะ tsc ผ่าน

## แบบ C — เฉพาะ motion / 3D

แนบ: `BRIEF.md` + `motion/` + `css/tokens.css` + `screens/*-shelf.png`

> ในเว็บนี้มีชั้นวางแฟ้ม 3D ทำด้วย react-three-fiber (`motion/DeskScene.tsx`)
> อ่านสีจาก tokens.css ตอน runtime ผ่าน `motion/theme.ts`
>
> ตอนนี้แฟ้มตั้งนิ่ง อยากให้มี motion ที่**สื่อความหมาย** ไม่ใช่ตกแต่ง เช่น
> ตอนเลื่อนไปอาคารอื่น ตอนเปิดแฟ้ม ตอนแฟ้มถูกเลือก
>
> ข้อบังคับ:
> — ต้องมีทางลง `prefers-reduced-motion: reduce` ที่ยังใช้งานได้ครบ
> — เครื่องเป้าหมายเป็น PC สำนักงานเก่า การ์ดจอ onboard เฟรมต้องไม่ตก
> — ถ้า WebGL ใช้ไม่ได้ ต้องมี fallback แบบ 2D (ตอนนี้มีอยู่แล้ว อย่าทำพัง)
> — สีแฟ้มแทนอาคาร ห้ามเปลี่ยนความหมาย
>
> เสนอมา 3 ไอเดีย บอกด้วยว่าแต่ละอันสื่ออะไร และกิน performance แค่ไหน
> ก่อนลงมือเขียน
